# 🕌 ডিঙ্গেল হাফিজিয়া মাদ্রাসা
## Student & Fee Management System

ডিঙ্গেল হাফিজিয়া মাদ্রাসার ছাত্র তথ্য, মাসিক ফি এবং রসিদ ব্যবস্থাপনার জন্য তৈরি একটি সহজ ও professional web-based management system।

**Run by - Dingel Ismail Welfare Trust**

---

## ✨ প্রধান সুবিধা

### 👨‍🎓 Student Management

- নতুন ছাত্র ভর্তি
- ছাত্রের তথ্য দেখা
- ছাত্রের তথ্য Edit করা
- ছাত্র Delete করা
- Roll অনুযায়ী ছাত্র খোঁজা
- নাম অনুযায়ী Search
- শ্রেণী অনুযায়ী Filter
- ছাত্রের মোবাইল নম্বর
- অভিভাবকের তথ্য
- মাসিক ফি
- এতিম ছাত্রের জন্য Free status
- গরিব ছাত্রের জন্য Free status

---

## 💰 Fee Management

- মাস অনুযায়ী Fee Collection
- Fee জমার Record
- Receipt Number
- Payment Date
- Student-wise Fee History
- Duplicate month payment warning
- মোট Fee Collection
- বর্তমান মাসের Collection

---

## 🧾 Receipt System

প্রতিটি Fee Collection-এর জন্য Receipt তৈরি হয়।

Receipt-এর মধ্যে থাকে:

- মাদ্রাসার নাম
- Receipt Number
- ছাত্রের নাম
- Roll Number
- Class
- Month
- Amount
- Date

### Receipt Features

- 🖨️ Print Receipt
- 📱 WhatsApp Receipt
